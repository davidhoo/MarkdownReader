# Markdown Reader v2.3.0

Raw 编辑模式新增左右分栏实时预览，编辑原文的同时直接看到渲染结果，并修复长文档末尾的滚动抖动。

## ✨ 新增

### 编辑模式左右分栏实时预览
此前在 Raw 编辑模式里写 Markdown，必须切到渲染模式才能看效果，来回切换打断写作节奏。现在可以在编辑模式直接左右分栏：左栏编辑原文，右栏同步显示渲染结果。

- 标题栏新增「切换分栏预览」按钮，点按开关左右分栏
- 预览在停止输入约 200 ms 后更新，连续快速输入不会反复重渲染，打字不卡顿
- 设置页「显示」分区新增「编辑时默认分栏」开关：开启后，默认显示模式为编辑时新窗口进入即默认分栏；默认关闭，绝不覆盖你已有的设置值
- `.txt` 纯文本模式不显示分栏按钮；渲染（Rendered）模式下分栏按钮不出现

## 🐛 修复

### 编辑器末尾滚动抖动
在长文档末尾连续回车、新增行或跳转到最后一行时，此前插入点可能被挤出可见区域，并与滚动位置相互拉扯，来回跳动。

- 改为在文档底部保留约一行高度的空间，确保插入点始终可见
- 消除末尾编辑时的滚动跳动
