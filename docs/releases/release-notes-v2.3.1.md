# Markdown Reader v2.3.1

稳定性回退版本：撤回 v2.3.0 引入的编辑模式分栏预览及关联改动，恢复到 v2.2.10 的稳定编辑与渲染行为。版本号高于 v2.3.0，已升级到 v2.3.0 的用户可通过应用内更新正常回到稳定版本。

## 🔙 回退

### 撤回 v2.3.0 的分栏预览与关联改动
v2.3.0 为 Raw 编辑模式引入了左右分栏实时预览、默认分栏设置以及编辑器末尾滚动的相关改动。v2.3.1 撤回以上全部改动，编辑与渲染行为回到 v2.2.10。

- 不再提供 Raw 编辑模式的左右分栏实时预览与「编辑时默认分栏」开关
- 编辑器滚动行为恢复 v2.2.10 的稳定状态

### 关于版本号
v2.3.1 是比 v2.3.0 更高的修复版本，应用内更新会把它识别为新版本。已安装 v2.3.0 的用户更新后，应用功能即回到 v2.2.10 的状态；仍在使用 v2.2.10 的用户同样会收到此次更新。

## ✅ 测试

- `swift build` 与 `swift build -c release` 编译通过
- 全部 195 个单元测试保持通过

- Apple Silicon 原生支持
