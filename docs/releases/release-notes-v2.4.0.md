# Markdown Reader v2.4.0

模式切换保持阅读位置 + 大纲导航统一顶部对齐，附一批滚动竞态修复。

## ✨ 新增

### Raw ↔ Rendered 模式切换保持阅读位置
此前切换渲染/原文模式会跳到行首，丢失行内阅读位置，长文档切换后常需重新滚动找回。本次引入基于小数源码位置的位置交接系统，切换后精确恢复到原来的阅读位置。

- 切换时采样当前视口顶部的小数源码位置（精确到行间比例），目标模式按同一位置定位
- 快速来回切换（A→B→A）时过期回调一律丢弃，不会停在中间状态
- 源码范围/DOM/Raw 排版任一不可用时降级到全文滚动进度兜底，两者都不可用时回到文档顶部

### 大纲导航统一顶部对齐
大纲点击此前的落点不一致：Raw 约在视口 1/3 处、Rendered 居中，点击同一标题会有明显跳变。现统一为目标标题距视口顶部约 12pt。

- 大纲导航与查找定位区分落点意图：大纲用顶部对齐，查找保留原有 Raw 约 1/3、Rendered 居中体验不变
- 大纲定位保留平滑动画（0.25 秒 easeOut），Rendered 边距按当前缩放换算成 CSS 像素，缩放时不变形
- 连续点击同一标题也会重新触发定位

## 🐛 修复

### 模式切换后位置跳回大纲标题的竞态
大纲导航后从 Rendered 切到 Raw，此前会先正确落位再跳回大纲标题位置（先对后错）。显式滚动请求现带 UUID 身份，一个视图端最多消费一次，模式切换清空后所有已排队旧请求自动失效。

### 渲染模式切换闪现空白或旧内容
Raw → Rendered 切换期间，WebView 内容替换未完成就让用户看到中间状态。现要求目标渲染世代完成且位置交接回执后 Raw 层才退场，且只有 `MR.replaceContent` 显式返回成功才报告完成。

### 编辑器末尾滚动抖动
长文档末尾连续回车、新增行或跳转最后一行时，插入点可能被挤出可见区域并与滚动位置相互拉扯。改为在文档底部保留约一行高度的空间，确保插入点始终可见。

### JavaScript 兜底分支报错
`scrollToLine` 最近 `data-line` 兜底分支存在变量重赋值错误，已修复。

## 🔧 变更

- **统一源码行坐标**：内部统一为 1-based 源码行号契约，禁止裸整数传行号，避免 0-based 与 1-based 混用导致的偏差
- **WebView 渲染闸门细化**：区分内容编辑、文件切换、强制刷新、模式切换四类变更，Raw 编辑时隐藏 WebView 不再随每次击键重渲染
