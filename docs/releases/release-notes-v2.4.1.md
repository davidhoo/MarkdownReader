# Markdown Reader v2.4.1

设置页分段控件与内容复制按钮的布局对齐修复。

## 🐛 修复

### 设置页"默认显示模式"分段控件左侧空隙
设置页"默认显示模式"的"渲染 / 编辑"分段控件相对区段标题有左侧缩进。原因是 `Picker("", ...)` 的空字符串标签仍占用布局空间。加 `.labelsHidden()` 隐藏无语义空标签后，分段控件左缘与区段标题对齐，200pt 宽度不变，与同页语言菜单 Picker 一致。

### Rendered 内容复制按钮右缘与 Raw 不对齐
开启"内容一键复制"后，Rendered 模式右上角的复制按钮比 Raw 模式多让出约 8px。原因是 Rendered 侧按钮位于 WebKit 滚动页面内，固定 8px 的滚动条占据了右侧空间。将 `right` 从 `11px` 改为 `3px`（11 − 8）后，两侧可见图标落在同一物理右缘。24×24pt 点击区、14×14px 图标、颜色、成功态与五秒复位均不变。
