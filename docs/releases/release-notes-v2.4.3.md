# Markdown Reader v2.4.3

更可靠的最近打开记录。

## ✨ 新增

### 成功打开才记录最近项
文件或目录加载成功后，才会写入「打开最近」记录和最后打开位置。打开不支持的文件、缺失文件、缺失目录或加载失败时，不会再把无效路径加入最近列表。

### 最近项去重与保留上限
记录前会标准化文件路径，并校验路径存在及其文件/目录类型。同一路径重复打开会移到最前，不会重复出现；最近项最多保留 10 条。

### 同步 macOS 系统最近文档
新增最近项时同步写入 macOS 系统最近文档，清空应用内最近列表时也会清除系统记录。应用内「打开最近」菜单由共享设置状态驱动，最近项变化后可及时刷新。
