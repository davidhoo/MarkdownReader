# Markdown Reader v2.4.4

修复 v2.4.3 中「打开最近使用」菜单不显示实际记录的问题。

## 🐞 修复

- 修复无最近项时 SwiftUI 将子菜单扁平化为单一禁用菜单项的问题
- 最近项菜单改为展开时动态刷新，新增/清除记录后无需重启应用
- 目录树侧边栏中的文件切换现在也会写入最近打开记录
- 保留原有去重、10 条上限、系统最近文档同步和清除菜单行为

## ✅ 测试

- `swift test` 全部 288 个测试通过
- `git diff --check` 无空白错误

## 🖥️ 系统要求

- macOS 26 (Tahoe) 或更高版本
- Apple Silicon 原生支持
