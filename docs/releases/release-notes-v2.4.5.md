# Markdown Reader v2.4.5

修复 v2.4.4 中应用启动后卡死并持续占用 CPU/内存的问题。

## 🐞 修复

- 修复「打开最近使用」菜单服务监听自身菜单更新、反复重建菜单项形成的通知循环，该循环导致 v2.4.4 启动后卡死并持续占用 CPU/内存
- 菜单挂接与首次填充改为幂等操作：标题仅在变化时写入，delegate 已挂接或子菜单已存在时不再重复填充
- 展开菜单时的动态刷新（最近文件/目录、空状态、清除菜单）行为保持不变

## ✅ 测试

- `swift test` 全部 290 个测试通过
- 新增重复挂接不重建菜单项的回归测试

## 🖥️ 系统要求

- macOS 26 (Tahoe) 或更高版本
- Apple Silicon 原生支持
