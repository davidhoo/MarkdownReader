# Markdown Reader v2.4.6

修复 v2.4.5 安装包中静态资源查找失败，导致无样式渲染，以及「渲染 → 编辑 → 渲染」切换假死的问题。

## 🐞 修复

- 修复现代 SwiftPM 资源包嵌套目录下 CSS/JS/字体查找返回 404，页面回退到浏览器默认字体与无样式排版的问题
- 新增统一资源定位器 `MarkdownResourceLocator`，主应用、Quick Look、PDF 导出共用，兼容嵌套与平铺两种 bundle 布局
- 模式切换失败时不再无限停留在不可交互的 Raw 遮罩：区分页面加载完成与渲染就绪，资源/JS 失败或滚动交接超时后回退到可编辑模式，并显示可重试提示
- 打包与发布增加渲染资源门禁（静态完整性 + WebPage 冒烟），避免错误资源布局再次进入发布包

## ✅ 测试

- `swift test` 全部 311 个测试通过
- 新增资源定位与模式切换失败出口回归测试
- 发布脚本对组装后的 `.app` 执行 WebPage 冒烟（字体、间距、正文替换、滚动回执）

## 🖥️ 系统要求

- macOS 26 (Tahoe) 或更高版本
- Apple Silicon 原生支持
