# Markdown Reader v2.4.7

修复 v2.4.6 安装包可能混入旧主程序的问题，并加强发布门禁，确保验收跑的是包内真实可执行文件。

## 🐞 修复

- 修复打包时重复传入 `--target`，SwiftPM 只编译最后一个目标，导致 Quick Look 新编、主程序仍复制历史二进制却配上新资源与版本号的问题
- 主产品与 Quick Look 扩展改为分别构建；每次打包使用独立构建目录，扩展只链接本次输出，并明确最低部署 macOS 26
- 发布验收改为启动 `.app` 内主程序的自检入口，验证实际链接的 HTML、资源定位、CSS、正文替换与滚动；旧主程序或缺资源会直接失败

## ✅ 测试

- `swift test` 全部通过
- 打包门禁对组装后的 `.app` 执行主程序自检（字体、间距、正文替换、滚动回执）
- 集成回归覆盖旧程序配新资源、资源缺失与损坏等拒绝场景

## 🖥️ 系统要求

- macOS 26 (Tahoe) 或更高版本
- Apple Silicon 原生支持
