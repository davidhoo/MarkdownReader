# Markdown Reader v2.4.8

目录里的文件夹符号链接现在可以像普通文件夹一样浏览，链接目标里的文件变化也会自动刷新到目录树。

## 🐞 修复

- 文件夹里的目录符号链接不再显示成文件，可以展开并列出目标里的内容，路径仍显示链接名
- 指回上级目录的链接环会停止展开，不会无限递归；无权限的链接目标仍显示为文件夹，不会让整个目录树加载失败
- 链接指向根目录之外时，目标里新增、删除、重命名文件也会自动刷新目录树；链接改指后监控范围随之更新，关闭目录时清理全部监控

## ✅ 测试

- `swift test` 全部 326 个测试通过
- 新增目录符号链接扫描与监控回归测试（相对/绝对链接、指向文件、悬空链接、链接环、无权限目标、隐藏文件设置、根外目标刷新、链接改指、关闭目录清理）

## 🍺 Homebrew

从本版本起，每次发布都会同步更新 Tap `davidhoo/markdownreader`，用 Homebrew 安装的用户可以直接升级：

```bash
brew update && brew upgrade --cask --greedy markdownreader
```

## 🖥️ 系统要求

- macOS 26 (Tahoe) 或更高版本
- Apple Silicon 原生支持
